# Micro-Bit-Games
# 🎮 BBC micro:bit Game Collection

A collection of pure MicroPython games built specifically for the **BBC micro:bit. Designed with minimalist arcade mechanics, snappy physics, background music, and fast-paced gameplay for the 5x5 LED matrix.

---

## 📋 Hardware Requirements

* **Target Board:** micro:bit
* **Language:** Python (MicroPython)
* **Audio:** Onboard speaker enabled
* **Inputs:** Buttons A & B

---

## 🕹️ Included Games

### 1. ⚡ Dash Master
An endless platform runner inspired by *Geometry Dash*. Speed increases as your score rises!

* **Controls:**
  * **Button A / B:** Jump / Double-Jump
* **Mechanics:**
  * Auto-scrolling world with floor platforms and embedded spikes (bright LEDs).
  * Smooth gravity and jump physics.
  * Custom background chip-tune melody.
  * One-hit death on spikes or pit falls.

---

### 2. 🏎️ Kartastrophe
A fast-paced dodge-and-survive racer where you navigate a multi-lane track avoiding obstacles.

* **Controls:**
  * **Button A:** Steer Left
  * **Button B:** Steer Right
* **Mechanics:**
  * Dynamic track generation with incoming hazards.
  * Progressive difficulty curve as speed ramps up.
  * High-score tracking with game-over jingles.

---

## 🚀 How to Play / Flash

1. Open the **[micro:bit Python Editor](https://python.microbit.org/)** in Google Chrome or Microsoft Edge.
2. Select a game folder from this repo and copy the code inside `main.py`.
3. Paste the code into the Python Editor.
4. Plug your micro:bit V2 into your computer via micro-USB.
5. Click **Send to micro:bit** (WebUSB) to flash the code directly.
